# B｜ChatGPT Sites 建置用後台規格（不提供給客戶）

## 核心流程

建立客戶 → 確認出生資料 → 系統排盤並保存快照 → Brian 錄音講解 → 貼上／匯入轉錄文字 → 整理報告草稿與提醒草稿 → Brian 審閱修正 → 發布報告 → 啟用已核准的每月提醒。

第一版以匯入既有轉錄文字為主；錄音上傳及自動轉錄可後續增加。匯入逐字稿不等於已核准對外發布。

## 逐字稿整理規則

1. 命盤資料以已保存的排盤結果為準；解讀內容以顧問講解為準。不得由 AI 新增未講過的運勢、喜忌、事件或月份。
2. 保留原始逐字稿，另存清理稿與報告稿，不覆寫來源。
3. 可刪除口頭禪、整理段落與重複句，但保留「可能、如果、傾向、要看……」等條件與不確定性。
4. 區分「Brian 解讀」「客戶自述」「整理文字」。講者不明時標為待確認，不自行認定。
5. 星曜、宮位、四化等專有名詞疑似轉錄錯誤時，對照命盤提出修正候選，讓 Brian 確認；不靜默修改。
6. 顧問說法與系統命盤不一致時，將該段標為待確認，避免自動採用任一方或改動命盤。
7. 年份依諮詢日期解析；月份須確認國曆／農曆／節氣。「明年」「下半年」「農曆三月」不可直接替換成未確認的國曆日期。
8. 出生時間不確定時保留不確定性，不代填時辰。不提供缺乏已確認輸入的精確判斷。
9. 不生成無依據的運勢分數、五行百分比、確定性預言、診斷或保健品建議。
10. 初稿所有段落須能在後台追溯到逐字稿段落 ID；有可靠時間戳才顯示時間，沒有則使用段落編號。
11. 重新匯入逐字稿或修改出生資訊後，建立新版本並重新審閱相關內容；舊提醒須暫停或標為待重新確認。
12. 內部筆記、原始逐字稿及來源定位僅管理員可見，不自動輸出到客戶 PDF。
